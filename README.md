# KINO PLAYBACK

Монитор для съёмочной площадки. Телефон в режиме **CAMERA** снимает и пишет оригинал, а планшет или телефон режиссёра в режиме **PLAYBACK** показывает живое изображение по локальной Wi-Fi-сети, управляет записью на камере и может писать принимаемый поток у себя.

Работает на iPhone, iPad, Android-телефонах и Android-планшетах. Каждое устройство может выступать в любой роли. Интернет, облако и аккаунты не нужны.

## Установка

Сборки делает GitHub Actions (**Actions → CI → последний зелёный прогон → Artifacts**):

* `kinoplayback-android-N`: `…-arm64.apk` подходит для современных телефонов, `…-universal.apk` — для любого Android, `.aab` — для Google Play. APK подписан отладочным ключом, для боевой публикации нужен свой keystore.
* `kinoplayback-ios-N`: `…-unsigned.ipa` без подписи. Ставится через Sideloadly со своим Apple ID, Sideloadly подписывает его сам.

## Как пользоваться

1. Подключите оба устройства к одной Wi-Fi-сети. Подойдёт и точка доступа на одном из телефонов.
2. На устройстве актёра откройте **CAMERA**. Чтобы режиссёр мог управлять записью, включите **Удалённый REC** (строка внизу или ⋯ → Настройки камеры).
3. На устройстве режиссёра откройте **PLAYBACK** и выберите камеру из списка. Если камера не находится, подключитесь через **QR-код** или **по IP-адресу**.
4. Подтвердите подключение на камере: «Разрешить» или «Всегда доверять».
5. В PLAYBACK большая красная кнопка запускает и останавливает запись на камере, а «Запись монитора» пишет принимаемый поток на этом устройстве.

Индикатор REC на мониторе загорается только после того, как камера подтвердила, что запись действительно началась.

## Разработка

```bash
flutter pub get
flutter test --exclude-tags golden     # протокол, REC, MP4, статистика, адаптивная вёрстка
flutter test --tags golden --update-goldens   # рендер экранов в test/goldens/*.png
```

Папки `ios/` и `android/` создаются командой `flutter create`, после неё нужно запустить `python3 tool/patch_platforms.py`: скрипт прописывает права, Bonjour, ориентации и минимальные версии ОС. Подробнее об устройстве проекта, протоколе и ограничениях — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
